Part 2. Micrograd — 최소형 Autodiff Tool

이 튜토리얼에서는 Python으로 minimalistic auto-differentiation utility인 Micrograd를 만들 것입니다. Autodiff는 TensorFlow와 Pytorch 같은 modern neural network libraries의 기반이며, neural networks 같은 계산 그래프에서 기울기를 자동으로 계산하는 알고리즘입니다. Autodiff는 매우 복잡한 장치라고 생각하기 쉽지만, Andrej는 자신의 강의에서 완전히 작동하는 Autodiff tool인 Micrograd를 약 100줄의 code만으로 만들 수 있음을 보여 줍니다.

Micrograd의 전체 버전(Andrej Karpathy 작성)은 여기에서 볼 수 있습니다 — https://github.com/karpathy/micrograd .

Autodiff tool의 목적은 어떤 함수든 그 매개변수 중 하나에 대한 기울기를 만들어 내는 것입니다. Neural network training에서 이것이 유용한 이유는 neural networks가 많은 매개변수를 가진 거대한 함수이기 때문입니다. 이를 개선하려면 목표에 대한 기울기를 계산해 함수의 각 매개변수를 어떻게 조금 움직여야 하는지 이해해야 합니다.

Autodiff tool은 계산 그래프를 추적하면서 작동합니다. 이 그래프를 이용해 어떤 매개변수가 함수 계산의 어떤 부분에 어떤 방식으로 영향을 주었는지 이해합니다. 앞으로 보겠지만 각 수학적 연산자는 서로 다른 도함수를 가지고 있으며, 연쇄 법칙으로 이 도함수를 이어 붙이면 매우 깊은 연산 집합의 기울기를 얻을 수 있습니다.

들어가 봅시다. 먼저 Python에서 하나의 숫자를 표현하면서 그 숫자가 관여하는 계산을 추적할 방법이 필요합니다. 이것이 Autodiff에 필요한 계산 그래프를 만드는 데 도움이 됩니다.

class Value : def __init__ ( self, data ): self .data = data def __repr__ ( self ): return f'Value(data= {self.data} )' a = Value( 2.0 ) b = Value(- 3.0 ) print (a) print (b)

Out:

Value (data= 2.0 ) Value (data=- 3.0 )

우리는 숫자의 값을 추적하는 Value라는 class를 만들고, Python이 이 object의 representation을 어떻게 print할지 알려 주는 __repr__ 함수를 구현했습니다. 아직 그다지 유용하지 않죠? 예를 들어 두 숫자를 더하고 싶다면 어떻게 할까요? 이 class에 computational abilities를 조금 추가해 봅시다.

class Value : def __init__ ( self, data ): self .data = data def __repr__ ( self ): return f'Value(data= {self.data} )' def __add__ ( self, other ): return Value( self .data + other.data) def __mul__ ( self, other ): return Value( self .data * other.data) a = Value( 2.0 ) b = Value(- 3.0 ) c = Value( 10.0 ) a * b + c # equivalent to (a.__mul__(b)).__add__(c)

Out:

Value(data=4.0)

좋습니다! 이제 Value class를 사용해 앞서 만든 함수를 재현할 수 있습니다. a * b + c는 (a.__mul__(b)).__add__(c)와 같습니다. Python은 +와 * 연산자를 사용할 때 __add__와 __mul__ 함수가 구현되어 있으면 그것을 사용해야 한다는 것을 알기 때문입니다. 하지만 아직 우리가 도함수를 계산하기 위해 원했던 계산 그래프는 얻지 못했습니다. 발생하는 계산을 추적하도록 class를 수정해 봅시다.

class Value : def __init__ ( self, data, prev=(), op= '' , label= '' ): self .data = data self ._prev = set (prev) self ._op = op self .label = label self .grad = 0 def __repr__ ( self ): return f'Value(data= {self.data} )' def __add__ ( self, other ): return Value( self .data + other.data, prev=( self , other), op= '+' ) def __mul__ ( self, other ): return Value( self .data * other.data, prev=( self , other), op= '*' ) a = Value( 2.0 , label= 'a' ) b = Value(- 3.0 , label= 'b' ) c = Value( 10.0 , label= 'c' ) ans = a * b + c # equivalent to (a.__mul__(b)).__add__(c) print ( f'ans._prev: {ans._prev} ' ) print ( f'ans._op: {ans._op} ' )

Out:

ans ._prev : { Value (data= 10.0 ), Value (data=- 6.0 )} ans ._op : +

class에 새로운 매개변수인 self._prev와 self._op를 추가했습니다. 이 매개변수는 각 계산에 참여한 요소와 사용된 연산자를 추적하는 데 쓰입니다. 최종 값의 _prev와 _op 값을 print했는데, 최종 값의 마지막 연산은 덧셈이었고 여기에는 c와 a*b가 참여했습니다. 내부 element의 _prev와 _op 값을 print했다면 2, -3, *를 보았을 것입니다. 곧 계산 그래프를 시각화하는 데 도움이 될 label 매개변수와, 각 매개변수의 도함수 정보를 담을 grad 매개변수도 추가했습니다.

이제 Value objects가 만든 계산 그래프를 시각화하는 데 도움이 되는 함수를 추가하겠습니다.

from graphviz import Digraph def trace ( root ): nodes, edges = set (), set () def build ( v ): if v not in nodes: nodes.add(v) for child in v._prev: edges.add((child, v)) build(child) build(root) return nodes, edges def draw_dot ( root ): dot = Digraph( format = 'svg' , graph_attr={ 'rankdir' : 'LR' }) nodes, edges = trace(root) for n in nodes: uid = str ( id (n)) dot.node(name=uid, label= f' {n.label} | data: {n.data: .4 f} | grad: {n.grad: .4 f} ' , shape= 'record' ) if n._op: dot.node(name=uid + n._op, label=n._op) dot.edge(uid + n._op, uid) for n1, n2 in edges: dot.edge( str ( id (n1)), str ( id (n2)) + n2._op) return dot a = Value( 2.0 , label= 'a' ) b = Value(- 3.0 , label= 'b' ) c = Value( 10.0 , label= 'c' ) e = a * b; e.label = 'e' d = e + c; d.label = 'd' f = Value(- 2.0 , label = 'f' ) L = d * f; L.label = 'L' draw_dot(L)

draw_dot 함수는 Value object를 받아 그것과 연결된 계산 그래프를 만듭니다. 먼저 trace 함수로 모든 노드와 edge를 재귀적으로 찾고, 이어서 graphviz library를 사용해 이 요소를 그립니다. e, d, L 노드의 이름이 시각화에 나타나도록 우리가 명시적으로 label을 붙였다는 점에 주목하세요.

지금까지 한 일을 recap해 봅시다. 덧셈과 곱셈 연산자로 구성된 간단한 계산 그래프를 만들 수 있는 Value class를 만들었습니다. 또한 graphviz library를 사용해 이 그래프를 시각화할 수 있습니다. 하지만 neural network 매개변수를 학습하려면 출력 노드에 대해 계산 그래프의 각 매개변수에 대한 기울기를 계산할 수 있어야 한다고 이미 보았습니다. 첫 단계로 각 기울기를 수동으로 계산하고 해당 grad 매개변수에 채우겠습니다.

Part 3. Micrograd — 기울기의 수동 계산

우리 함수는 a, b, c, d, e, f, L이라는 일곱 매개변수로 구성됩니다. 출력인 L에 대해 각각의 기울기를 생각해 봅시다.

  • L의 자기 자신에 대한 기울기는 단순히 1입니다. 왜일까요? L에 h를 더하면 L은 얼마나 변할까요? 당연히 h만큼 변합니다. 기울기는 상대 변화이므로 답은 h/h = 1입니다. 쉽죠?
  • 이제 L에 대한 d의 기울기는 무엇일까요? L=d*f입니다. 미적분에서 dL/dd = f임을 압니다. 도함수의 정의로도 증명해 봅시다. 기억하자면 정의는 (f(x+h) — f(x))/h, 즉 rise over run입니다. L을 d에 대해 도함수로 구하면 ((d+h) * f-d * f)/h가 되고, 이는 (df + hf — df)/h, 즉 hf/h이며, 결국 f = -2입니다.
  • 마찬가지로 dL/df = d = 4입니다.
  • 이제 까다로운 부분입니다. dL/dc는 무엇일까요? c를 조금 바꿀 때 L의 변화 비율은 무엇일까요? 영향이 직접적이지 않고 변수 d를 통과하기 때문에 더 까다롭습니다. 다행히 미적분에는 연쇄 법칙이 있습니다. 뜻은 무엇일까요? d를 통과하는 dL/dc를 계산하려면 dL/dd와 dd/dc를 계산한 뒤 둘을 곱하면 됩니다. 쉽습니다! 우리는 이미 dL/dd를 알고 있습니다. dd/dc는 d=c+e이므로 c에 h를 더할 때 d가 얼마나 변할까요? 당연히 h만큼입니다. 도함수는 변화 비율이므로 h/h=1입니다. 따라서 연쇄 법칙에 의해 dL/dc = dL/dd*dd/dc = f*1 = f = -2가 됩니다.
  • symmetry에 의해 dL/de = f*1 = -2입니다.
  • dL/da는 어떨까요? 연쇄 법칙에 의해 dL/de * de/da입니다. 우리는 이미 dL/de를 알고 있습니다. e=a*b에 대한 de/da는 앞서 본 것처럼 b입니다. 따라서 dL/da = dL/de*de/da = f * b = -2 * -3 = 6입니다.
  • symmetry에 의해 dL/db = dL/de * de/db = f * a = -2 * 2 = -4입니다.

비디오 강의에서 Andrej는 우리가 앞서 한 것처럼 기울기의 정의(rise over run 확인)를 사용해 모든 기울기가 올바른지 증명합니다. 이 글에서는 간결함을 위해 생략하겠습니다.

마지막으로 우리가 찾은 모든 기울기를 각 매개변수에 수동으로 할당하고 계산 그래프를 다시 봅시다.

Part 4. Micrograd — 간단한 neuron 만들기

이제 실제 neural networks로 넘어갈 준비가 되었습니다. 하지만 먼저 artificial neuron이란 무엇일까요?

Figure 1에는 3개의 입력인 X1, X2, X3를 가진 artificial neuron이 묘사되어 있습니다. 각 입력은 대응하는 가중치와 곱해지고, 이 곱셈들이 모두 더해집니다. 추가로 bias term b도 더해집니다. 이 bias term은 neuron에 내재되어 있으며 모든 입력에 대해 동일합니다. 마지막으로 activation 함수가 적용됩니다. 이 튜토리얼에서는 입력을 -1과 1 사이로 squash하는 Tanh 함수를 사용할 것입니다. artificial neuron은 실제 neuron에서 neurons가 synapses를 통해 다른 neurons의 입력을 받고 axons를 통해 출력을 보내는 현상을 느슨하게 모방합니다.

이제 두 가지 선택지가 있습니다. 하나는 Value에 exp 함수를 구현하는 것입니다. 이렇게 하면 덧셈(뺄셈), 곱셈(나눗셈), 거듭제곱이라는 기본 구성 요소로 Tanh 함수를 만들 수 있습니다. 두 번째 선택지는 Tanh 함수를 직접 구현하는 것입니다. backpropagation에서는 계산 그래프의 가장 작은 부분을 반드시 명시적으로 구현할 필요는 없습니다. forward pass와 도함수만 구현할 수 있다면 임의로 큰 구성 요소를 사용해도 됩니다. 우리는 두 번째 선택지를 선택해 Value class에 Tanh를 구현하겠습니다.

class Value : def __init__ ( self, data, prev=(), op= '' , label= '' ): self .data = data self ._prev = set (prev) self ._op = op self .label = label self .grad = 0 def __repr__ ( self ): return f'Value(data= {self.data} )' def __add__ ( self, other ): return Value( self .data + other.data, prev=( self , other), op= '+' ) def __mul__ ( self, other ): return Value( self .data * other.data, prev=( self , other), op= '*' ) def tanh ( self ): x = self .data t = (math.exp( 2 *x) - 1 )/(math.exp( 2 *x) + 1 ) out = Value(t, ( self ,), 'tanh' ) return out

  • 마찬가지로 x2w2.grad = 1 * x1w1x2w2.grad = 0.5입니다.
  • x1.grad의 경우 곱셈 연산이며, 국소 기울기는 다른 매개변수입니다. 여기에 연쇄 법칙을 적용하면 x1.grad = x1w1.grad * w1 = -3 * 0.5 = -1.5입니다.

Part 6. Backward 연산 구현

이제 Value class의 각 연산에 _backward 함수를 추가하겠습니다. 이 함수는 우리가 수동으로 하지 않아도 각 계산 노드의 기울기를 계산합니다.

class Value : def __init__ ( self, data, prev=(), op= '' , label= '' ): self .data = data self ._prev = set (prev) self ._op = op self .label = label self .grad = 0 self ._backward = lambda : None def __repr__ ( self ): return f'Value(data= {self.data} )' def __add__ ( self, other ): out = Value( self .data + other.data, prev=( self , other), op= '+' ) def _backward (): self .grad = 1.0 * out.grad other.grad = 1.0 * out.grad out._backward = _backward return out def __mul__ ( self, other ): out = Value( self .data * other.data, prev=( self , other), op= '*' ) def _backward (): self .grad = other.data * out.grad other.grad = self .data * out.grad out._backward = _backward return out def tanh ( self ): x = self .data t = (math.exp( 2 *x) - 1 )/(math.exp( 2 *x) + 1 ) out = Value(t, ( self ,), 'tanh' ) def _backward (): self .grad = ( 1.0 - out.data ** 2 ) * out.grad out._backward = _backward return out

code를 살펴봅시다.

  • 기본 _backward 함수는 아무것도 반환하지 않습니다. 어떤 연산의 일부가 아닌 leaf 노드에는 이것이 적용됩니다.
  • 또한 _backward 함수는 연쇄 법칙에 따라 두 피연산자의 기울기를 설정합니다. 이는 국소 도함수(1)에 chain의 이전 도함수, 즉 out의 도함수를 곱한 것입니다. out의 도함수는 이미 계산되었다고 가정한다는 점에 유의하세요.
  • 곱셈의 경우도 비슷하지만, 국소 기울기가 1이 아니라 다른 피연산자입니다. self에 대해서는 other.grad, other에 대해서는 self.grad입니다.
  • Tanh 연산에는 other가 없으므로 self.grad만 설정하면 됩니다. 앞과 마찬가지로 Tanh의 국소 도함수를 사용하고, 이미 계산되었다고 가정하는 out의 도함수를 곱합니다.

_backward 함수를 사용해 봅시다.

o.grad = 1.0 o._backward() n._backward() b._backward() x1w1x2w2._backward() x2w2._backward() x1w1._backward() draw_dot(o)

o.grad = 1.0을 수동으로 설정해야 했다는 점에 주목하세요. 왜일까요? 각 노드의 placeholder 기울기 값이 0이기 때문입니다. backward 함수는 항상 계산 그래프의 이전 기울기에 의존하며, 그것이 0이면 모든 기울기가 0이 됩니다. 한번 생각해 보세요.

하지만 _backward 함수를 수동으로 호출해야 할까요? 물론 아닙니다. 여기서 loop를 사용할 수 있지만, 노드를 특정 order로 iterate해야 합니다. 나가는 edge로 연결된 neighbors의 기울기가 아직 계산되지 않은 노드에서 _backward를 호출할 수는 없습니다. 이를 위해 topological sorting이라는 것이 필요합니다.

예시로 topological sorting이 무엇인지 이해해 봅시다. 다음 그래프를 보세요.

이 그래프를 topologically sort하는 세 가지 선택지는 다음과 같습니다(Wikipedia — https://en.wikipedia.org/wiki/Topological_sorting 에서 가져옴).

  • 5, 7, 3, 11, 8, 2, 9, 10 (visual top-to-bottom, left-to-right)
  • 3, 5, 7, 8, 11, 2, 9, 10 (smallest-numbered available vertex first)
  • 5, 7, 3, 8, 11, 10, 9, 2 (fewest edge first)

모든 sorting 선택지에서 outgoing edge가 노드 u에서 노드 v로 향한다면, topological sorting에서 노드 v는 u 뒤에 온다는 점에 주목하세요.

topological sorting의 단순한 형태를 구현하고 이를 사용해 계산 그래프에 _backward 함수를 적용해 봅시다.

topo = [] visited = set () def build_topo ( v, topo, visited ): if v not in visited: visited.add(v) for child in v._prev: build_topo(child, topo, visited) topo.append(v)

위 code는 topological sorting의 간단한 implementation입니다. recursion을 사용해 어떤 노드의 모든 offspring이 그 노드보다 먼저 topo list에 추가되도록 합니다. 이 함수를 명시적으로 호출하는 대신, code를 조금 더 깔끔하게 만들기 위해 Value class의 일부로 만들겠습니다. 그러면 전체 계산 그래프의 기울기를 계산하기 위해 하나의 함수만 호출하면 됩니다.

class Value : def __init__ ( self, data, prev=(), op= '' , label= '' ): self .data = data self ._prev = set (prev) self ._op = op self .label = label self .grad = 0 self ._backward = lambda : None def __repr__ ( self ): return f'Value(data= {self.data} )' def __add__ ( self, other ): out = Value( self .data + other.data, prev=( self , other), op= '+' ) def _backward (): self .grad = 1.0 * out.grad other.grad = 1.0 * out.grad out._backward = _backward return out def __mul__ ( self, other ): out = Value( self .data * other.data, prev=( self , other), op= '*' ) def _backward (): self .grad = other.data * out.grad other.grad = self .data * out.grad out._backward = _backward return out def tanh ( self ): x = self .data t = (math.exp( 2 *x) - 1 )/(math.exp( 2 *x) + 1 ) out = Value(t, ( self ,), 'tanh' ) def _backward (): self .grad = ( 1.0 - out.data ** 2 ) * out.grad out._backward = _backward return out def backward ( self ): topo = [] visited = set () def build_topo ( v ): if v not in visited: visited.add(v) for child in v._prev: build_topo(child) topo.append(v) build_topo( self ) self .grad = 1 for node in reversed (topo): node._backward()

이 경우 a와 b의 기울기는 무엇이어야 할까요? 곱셈 노드에 따르면 a의 기울기는 3, b의 기울기는 -2여야 합니다. 두 숫자의 곱셈에서 국소 기울기는 다른 피연산자이기 때문입니다. 덧셈 노드에 따르면 둘의 기울기는 모두 -6이어야 합니다. 이 경우 계산이 덧셈 노드를 기반으로 이루어진 것을 볼 수 있는데, 이는 임의의 topological sorting 때문일 뿐입니다.

왜 이런 일이 생길까요? __add__ 연산의 _backward 함수를 관찰해 봅시다.

def _backward (): self .grad = 1.0 * out.grad other.grad = 1.0 * out.grad

self와 other의 기울기를 설정하면서, 이미 계산되었을 수 있는 이전 값을 무시하고 있음을 볼 수 있습니다. backpropagation에서 특정 노드의 기울기는 더해지는 방식으로 계산됩니다. 모든 계산의 영향이 더해지는 것입니다.

_backward 함수에서 = 연산자를 +=로 바꾸면 이 상황을 아주 간단히 고칠 수 있습니다. 그러면 영향이 더해집니다. 다음과 같습니다.

def _backward (): self .grad += 1.0 * out.grad other.grad += 1.0 * out.grad

_backward 함수를 고치고 이전 code를 다시 실행하면 다음 계산 그래프를 얻습니다.

+와 * 노드의 영향이 서로 덮어쓰지 않고 더해져 a와 b에 대해 올바른 기울기가 나온 것을 볼 수 있습니다.

Part 7. 상수 지원 추가

이 code를 실행하면 어떻게 될까요?

a = Value( 2.0 ) a + 2

AttributeError: ‘int’ object has no attribute ‘data’ 라는 error가 납니다. 왜일까요? Value의 __add__ 함수는 다른 Value object를 기대하기 때문입니다. __add__ 함수에 다음 fix를 적용하면(그리고 __mul__ 함수에도 비슷하게 적용하면) 이를 간단히 해결할 수 있습니다.

def __add__ ( self, other ): other = other if isinstance (other, Value) else Value(other) out = Value( self .data + other.data, prev=( self , other), op= '+' ) def _backward (): self .grad += 1.0 * out.grad other.grad += 1.0 * out.grad out._backward = _backward return out

other가 Value type인지 확인하고, 아니라면 변환합니다 :)

이제 이 code를 실행하면 어떻게 될까요?

a = Value( 2.0 ) 2 + a

작동할 것처럼 보이죠? 하지만 그렇지 않습니다. TypeError: unsupported 피연산자 type(s) for +: ‘int’ and ‘Value’ 라는 error가 납니다. 이 경우 Python은 2.__add__(a)를 실행하려고 합니다. Python의 기본 __add__ 함수는 Value objects를 어떻게 다뤄야 하는지 당연히 모릅니다. 우리가 만든 것이니까요. 어떻게 고칠까요?

이를 위해 Python은 __radd__ 함수를 지원합니다.

def __radd__ ( self, other ): return self + other

작동 방식은 이렇습니다. 어떤 이유로 Python이 __add__ 호출에 실패하고 __radd__가 available하다면, __add__의 피연산자를 바꿔 __radd__를 호출합니다. 따라서 a + 2가 대신 호출되고, 이것은 이미 작동함을 보았습니다. 물론 __mul__과 __rmul__도 같은 방식으로 처리합니다.

Part 8. Tanh를 구성 요소로 나누기

현재 Value class는 Tanh 연산을 하나의 complete block으로 지원합니다. Tanh 계산을 계산 그래프에 명시적으로 포함해 Tanh를 constituting parts로 나누고 싶다면 어떻게 할까요?

이를 위해 몇 가지 연산자를 추가해야 합니다. Tanh implementation을 다시 떠올려 봅시다.

def tanh ( self ): x = self .data t = (math.exp( 2 *x) - 1 )/(math.exp( 2 *x) + 1 ) out = Value(t, ( self ,), 'tanh' ) return out

이 연산을 나누려면 거듭제곱(exp), power(pow), 나눗셈, 뺄셈 연산자가 필요합니다.

나눗셈은 다음과 같이 구현합니다.

def __truediv__ ( self, other ): return self * other ** - 1

방금 사용한 연산은 수학적으로 self/other와 equivalent합니다. 하지만 아직 구현하지 않은 power(**) 연산자에 의존한다는 점에 주목하세요. 그것을 구현해 봅시다.

def __pow__ ( self, other ): assert isinstance (other, ( int , float )), "only supporting pow for int/float" out = Value( self .data ** other, ( self ,), f'** {other} ' ) def _backward (): self .grad += other * ( self .data ** (other - 1 )) * out.grad out._backward = _backward return out

__pow__에 대해 몇 가지를 짚어 봅시다. 첫째, int 또는 float 입력만 지원합니다. 더 복잡한 입력, 즉 임의의 Value objects에 대한 power는 지원하지 않는다는 뜻입니다. 그러면 도함수 rules가 달라지기 때문입니다. 둘째, 미적분 rule dxⁿ/dx=nxⁿ⁻¹을 사용해 _backward 함수를 구현합니다.

마지막으로 뺄셈을 지원해야 하는데, 이를 위해 덧셈을 다음과 같이 활용합니다.

def __sub__ ( self, other ): return self + (-other)

이를 위해 negation을 지원해야 하므로 다음을 추가합니다.

def __neg__ ( self ): return self * - 1

Part 9. Micrograd와 Pytorch 비교

지금까지 우리는 직접 auto-differentiable computation 그래프 class인 Value를 개발했습니다. 그것이 예상대로 작동하고, supported 구성 요소로 구성되어 있기만 하면 임의의하게 복잡한 그래프를 back-propagate할 수 있음을 검증했습니다.

Part 10. multi-layer perceptron (MLP) 만들기

주요 building block인 Value class를 사용해 이제 첫 neural network를 만들겠습니다. 간단한 MLPs를 만들 수 있는 class를 작성합니다. 먼저 하나를 만들고, 특정 task에 대해 가중치를 최적화하기 위해 backpropagation을 어떻게 사용하는지 이야기해 봅시다.

class Neuron : def __init__ ( self, nin, layer_idx, neuron_idx ): self .layer_idx = layer_idx self .neuron_idx = neuron_idx self .w = [Value(random.uniform(- 1 , 1 ), label= f'w^ {layer_idx} _( {neuron_idx} {i+ 1 } )' ) for i in range (nin)] self .b = Value(random.uniform(- 1 , 1 ), label= f'b^ {layer_idx} _ {neuron_idx} ' ) def __call__ ( self, x ): act = sum ((wi*xi for wi, xi in zip ( self .w, x)), self .b) out = act.tanh() out.label = f'L_ {self.layer_idx} {self.neuron_idx} ' return out def parameters ( self ): return self .w + [ self .b] class Layer : def __init__ ( self, nin, nout, layer_idx ): self .neurons = [Neuron(nin, layer_idx, neuron_idx=i+ 1 ) for i in range (nout)] def __call__ ( self, x ): outs = [n(x) for n in self .neurons] return outs[ 0 ] if len (outs) == 1 else outs def parameters ( self ): return [p for neuron in self .neurons for p in neuron.parameters()] class MLP : def __init__ ( self, nin, nouts ): sz = [nin] + nouts self .layers = [Layer(sz[i], sz[i+ 1 ], layer_idx=i+ 1 ) for i in range ( len (nouts))] def __call__ ( self, x ): for layer in self .layers: x = layer(x) return x def parameters ( self ): return [p for layer in self .layers for p in layer.parameters()]

현재 implementation에서는 기울기 값을 비우는 것을 잊었기 때문에, 서로 다른 network 가중치로 수행된 이후 forward pass들를 거치며 기울기가 누적됩니다. 물론 이것은 말이 되지 않으므로 간단한 fix가 필요합니다.

def training_loop ( n_steps, learning_rate ): for k in range (n_steps): # forward pass ypred = [n(x) for x in xs] loss = sum ((yout - ygt)** 2 for ygt, yout in zip (ys, ypred)) for p in n.parameters(): p.grad = 0.0 # backward pass loss.backward() for p in n.parameters(): p.data -= learning_rate * p.grad print (k, loss.data)

backward pass 전에 모든 network 매개변수를 iterate하며 값 0을 할당합니다.

이 toy 예시에서는 큰 문제가 되지 않았고, 오히려 model이 더 빨리 converge하도록 도왔습니다. 문제 자체가 매우 쉽고, 기울기를 accumulate하는 것이 massive learning rate를 사용하는 것과 비슷했기 때문입니다. 비슷한 loss 상태에 도달하려면 20 steps 대신 수백 training steps가 필요했습니다. 하지만 이것은 분명 bug이며, larger networks에서는 말도 안 되는 결과로 이어질 수 있습니다.
